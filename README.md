# Ecommercxe Tutorial

## Project Objective
This project is a microservices-based E-commerce application.
It demonstrates how different services communicate in a real-world system.

## Technologies Used
- Java
- Spring Boot
- Spring Cloud
- Maven
- MySQL
- REST APIs

## Microservices Included
- API Gateway
- Config Server
- Discovery Server
- User Service
- Product Service
- Order Service
- Payment Service
- Inventory Service
- Notification Service

## Project Architecture
This project follows a microservices architecture where each service has its own responsibility.
Services communicate using REST APIs and are registered with a discovery server.

## How to Run the Project
1. Start Config Server
2. Start Discovery Server
3. Start API Gateway
4. Start all other services one by one



## Conclusion
This project helps in understanding microservices, service discovery, and distributed systems.
